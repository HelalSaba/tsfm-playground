TSFM AR(p) scalar/no-patching experiment commands
====================================================

Assumptions
-----------
- Project env is synced with uv, e.g.:
    uv sync
- Run commands with:
    uv run python ...
- Current merged files are in place:
    src/playground/data/ar.py
    scripts/experiment_arp_sanity.py
    scripts/experiment_arp_perturbation.py
    scripts/experiment_arp_attention.py
    scripts/experiment_arp_cross_eval_all.py
    scripts/experiment_arp_mixed_icl.py
- Scalar/no-patching setting is:
    --patch-size 1 --patch-stride 1
  These are defaults in our scripts, so they are not repeated below.
- Always use:
    --use-rope
  because without positional information the AR sanity test fails.
- use --device cpu to force CPU.

====================================================

Train AR(1) specialist:

uv run python scripts/experiment_arp_sanity.py --ar-order 1 --steps 5000 --use-rope --device auto --output-dir outputs/ar1/scalar/sanity --run-name ar1_scalar_rope_seed7

====================================================
CONTEXT-SHIFT PERTURBATION (slot vs content)
====================================================

Withhold the most recent N true lags at eval time (fixed target). Model lag k
holds true lag k+N. N=1 withholds true lag 1. Use existing specialists; no retrain.
Outputs use suffix _shift{N} so they do not overwrite baseline perturbation files.

# AR(6), N=1
uv run python scripts/experiment_arp_perturbation.py --checkpoint outputs/ar6/scalar/sanity/ar6_scalar_rope_seed7_best_model.pt --eval-n 4000 --perturbation permute --context-shift 1 --device auto --output-dir outputs/ar6/scalar/perturbation --run-name ar6_scalar_rope_seed7_perturbation

# AR(7), N=1
uv run python scripts/experiment_arp_perturbation.py --checkpoint outputs/ar7/scalar/sanity/ar7_scalar_rope_seed7_best_model.pt --eval-n 4000 --perturbation permute --context-shift 1 --device auto --output-dir outputs/ar7/scalar/perturbation --run-name ar7_scalar_rope_seed7_perturbation

# Follow-up: any N (e.g. shift 2)
# uv run python scripts/experiment_arp_perturbation.py --checkpoint outputs/ar7/scalar/sanity/ar7_scalar_rope_seed7_best_model.pt --eval-n 4000 --perturbation permute --context-shift 2 --device auto --output-dir outputs/ar7/scalar/perturbation --run-name ar7_scalar_rope_seed7_perturbation


====================================================
TRAIN WITH CONTEXT-SHIFT (misaligned / multi-step task)
====================================================

Train while withholding the most recent N true lags; target stays the next step
after the full window. Tests whether a slot-2 bias is hard-wired or learnable-away.
Checkpoint args include train_context_shift. For perturbation of these models, pass
matching --context-shift N so eval stays on the same misaligned task.

# Train AR(15) with N=1
uv run python scripts/experiment_arp_sanity.py --ar-order 15 --steps 9000 --use-rope --train-context-shift 1 --device auto --output-dir outputs/ar15/scalar/sanity_trainshift1 --run-name ar15_scalar_rope_seed7_trainshift1

# Perturbation on that checkpoint (keep eval shift matched to train)
uv run python scripts/experiment_arp_perturbation.py --checkpoint outputs/ar15/scalar/sanity_trainshift1/ar15_scalar_rope_seed7_trainshift1_best_model.pt --eval-n 4000 --perturbation permute --context-shift 1 --device auto --output-dir outputs/ar15/scalar/perturbation_trainshift1 --run-name ar15_scalar_rope_seed7_trainshift1_perturbation


====================================================
CONTEXT-SHIFT SUITE (train ± shift × AR1-7 × 3 perturbations)
====================================================

Retrains AR(1)..AR(7) with train_context_shift=0 and =1, runs attention on each
checkpoint, runs perturbation at eval shift 0 and 1 for permute/zero/noise, and
writes comparison plots (both blues + both oranges). Sanity scatters and attention
live under each ar*/sanity/ and ar*/attention/.

Full suite (long: 14 trainings + 14 attention + many evals). Default root is
outputs/context_shift_suite_seed{seed} (seed appears in folder + plot titles):

uv run python scripts/run_context_shift_suite.py --seed 7 --device auto

Rerun with a different seed (writes a separate folder, does not overwrite seed7):

uv run python scripts/run_context_shift_suite.py --seed 13 --device auto

Dry-run (print plan only):

uv run python scripts/run_context_shift_suite.py --seed 7 --dry-run

Attention-only resume on an existing suite (skip train + perturb):

uv run python scripts/run_context_shift_suite.py --seed 7 --skip-train --skip-perturb --device auto

Skip attention entirely:

uv run python scripts/run_context_shift_suite.py --seed 7 --no-attention --device auto

Smaller smoke (AR6-7, permute only):

uv run python scripts/run_context_shift_suite.py --seed 7 --orders 6 7 --perturbations permute --steps 500 --eval-n 256 --device auto

Resume / skip finished pieces:

uv run python scripts/run_context_shift_suite.py --seed 7 --skip-train --skip-perturb --skip-attention --device auto
